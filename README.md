# FlappyBird
This is a simple Flappy Bird recreation written in VB (Visual Basic) that runs entirely in the command prompt. It was inspired by a boring computer science class and serves as a fun console-based take on the classic game.

# Features
- Text-Based Graphics: The game runs in the command prompt using characters to represent the bird and obstacles.

- Simple Controls: Easy-to-learn mechanics that replicate the original Flappy Bird gameplay.

- Minimalistic & Lightweight: No external dependencies—just run the VB script and play.

# Controls
-Press Space: Makes the bird jump.

-Avoid obstacles: Time your jumps to pass through gaps in the pipes.

-Survive as long as possible: The game ends if you hit a pipe or the ground.
